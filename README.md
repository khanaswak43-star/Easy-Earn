# 🎯 EasyEarn - AI Caption & Prompt Generator

A modern Android app for generating stunning captions and prompts for your photos. Built with Kotlin and Material Design 3.

## ✨ Features

- 🎨 **Beautiful Material Design 3 UI** - Modern, responsive interface
- 📝 **Smart Caption Generation** - AI-style captions in Hinglish
- 🏷️ **Category Based** - Bikes, Fashion, Food, Travel, and more
- 📋 **Copy to Clipboard** - One-tap copying
- 📤 **Share to Social Media** - Direct sharing to WhatsApp, Instagram, etc.
- 🌙 **Dark Mode Support** - Eye-friendly dark theme
- ⭐ **Premium Features** - Unlock advanced captions
- 🎬 **Smooth Animations** - Delightful user experience

## 🚀 Getting Started

### Prerequisites
- Android Studio (Latest)
- JDK 11 or higher
- Android SDK 35+
- Kotlin 2.0.21+

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/khanaswak43-star/Easy-Earn.git
   cd Easy-Earn
   ```

2. **Open in Android Studio**
   - Open Android Studio
   - Click "Open an Existing Project"
   - Select the Easy-Earn folder
   - Wait for Gradle sync to complete

3. **Run the app**
   - Connect an Android device or start an emulator
   - Click "Run" or press Shift + F10
